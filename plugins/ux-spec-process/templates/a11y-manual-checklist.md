# A11y Manual Checklist

Mandatory Tier 1–2, advisory Tier 3, until automated validation is wired.

- [ ] Keyboard-only navigation of all flows
- [ ] Visible focus indicator
- [ ] Logical focus order
- [ ] All interactive elements labeled for screen readers
- [ ] Images/icons have text alternatives
- [ ] Color not sole information carrier
- [ ] Contrast meets AA
- [ ] Error messages identified in text and programmatically
- [ ] No keyboard traps
- [ ] Content reflows at 200% zoom
